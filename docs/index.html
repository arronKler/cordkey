01 / HARDWARE ENGINEERING

Built around real headset physics.

Why naive key-remappers fail on USB-C EarPods — and how CordKey solves inline microphone shorting cleanly.

FIG 01 · CTIA INLINE CIRCUIT MIC SHORTED ON HOLD

Hardware cause: shared mic bias line

While you hold the EarPods center button, the switch pulls MIC+ directly to ground so the USB-C ADC detects the press — physically muting the EarPods mic until release.

FIG 02 · CLEAN-AUDIO TIMELINE 60MS CONTACT SETTLE

CordKey's fix: Clean-Audio Toggle + Mic Lock

Click Toggle waits 60 ms after release (zero click pop), and cuts on the 2nd press-down. Or lock input to your MacBook Pro Mic in 1 click to keep Hold-to-Talk with clean audio.

02 / ARCHITECTURE & FEATURES

Six systems, one tiny menu bar app.

Pure Swift + Apple frameworks. Zero Electron, zero background daemons, zero telemetry.

01

Universal USB HID + Learn Button

Supports both Consumer media keys and office Telephony keys (Mic Mute, Hook Switch, Call Hold). Press any button on any USB headset to bind automatically.

IOHIDManager · 0x0C + 0x0B · Seize
02

CoreAudio Input Mic Lock

Lock your preferred microphone by stable CoreAudio UID so plugging in USB-C EarPods never silently steals your default input device.

kAudioDevicePropertyDeviceUID
03

Multi-Action: Tap / 2×Tap / Hold

Assign independent Short Tap (native or shortcut), Double Tap, and Hold Delay (250 / 300 / 500 ms) actions to one button with zero delay when double-tap is off.

--hold-ms 300 --tap --double-tap
04

Floating HUD & Toggle Timeout

Non-activating frosted-glass pill floats over full-screen Spaces with elapsed timer and click-to-release, backed by optional 1m / 2m / 5m auto-release.

NSPanel · .nonactivatingPanel
05

Per-Headset Auto-Profiles

Saves distinct mappings and trigger modes per VID:PID — swap between an office Jabra headset and travel EarPods seamlessly.

VID:PID Profile Store · Hot-Plug
06

App-Aware Rules & Bluetooth Mode

Auto-pause in Music/IINA, override Play for mute in Lark/Zoom/Discord, and optionally enable Bluetooth Play interception for AirPods & Sony headsets.

NSWorkspace + AVRCP Media Tap
03 / COMPATIBILITY MATRIX

Hardware support at a glance.

Hardware Protocol Hold Toggle Notes
Apple USB-C EarPods USB · 0x0C (0x05ac:0x110b) Yes* Yes *Pair with Click Toggle or Mic Lock to MacBook Mic for clean audio.
Jabra / Poly / Logitech / HyperX USB USB · 0x0C + 0x0B Yes Yes Supports dedicated Mic Mute (0x2F) & Hook Switch (0x20) via Learn Button.
USB-C to 3.5 mm DAC Dongles USB · 0x0C Yes Yes Exposes standard Consumer HID buttons; Mac keyboard F8 stays untouched.
AirPods / Sony / Bose (Bluetooth) AVRCP · Media Tap — Yes Opt-in Bluetooth Compatibility Mode (uses Click Toggle; also taps F8).

OPTION 01 · RECOMMENDED · ZERO GATEKEEPER PROMPT
Install via Homebrew

Installs the universal CordKey.app into /Applications and links the cordkey CLI into your PATH — no manual quarantine step needed.

brew install --cask --no-quarantine arronKler/tap/cordkey
OPTION 02 · DIRECT INSTALLER
Download Universal DMG

No Homebrew required. Open the DMG and drag CordKey.app into Applications first (don't double-click inside the DMG).

Download .dmg .zip Archive
STEP 01
Install to Applications Choose Homebrew or the DMG above so CordKey.app lives in /Applications.
STEP 02
Grant Accessibility Click the CordKey menu bar icon → Open Settings → enable CordKey in Accessibility.
STEP 03
Bind & Talk Pick Right Option / Fn / F13 (or record any chord), plug in your headset, and go.
Using the DMG? First-launch Gatekeeper note: CordKey is ad-hoc signed (not notarized). Clear quarantine once after dragging to Applications, or allow in System Settings → Privacy & Security:
xattr -cr /Applications/CordKey.app && open /Applications/CordKey.app
Developers: CLI Usage & Build from Source Swift · Zero Dependencies ▾ 
git clone https://github.com/arronKler/cordkey.git && cd cordkey
make app-install && open /Applications/CordKey.app

# Standalone CLI examples
./bin/cordkey devices                                       # list USB Consumer/Telephony headsets
./bin/cordkey probe                                         # live-inspect raw PAGE:USAGE codes
./bin/cordkey --play right_option --toggle --sound          # EarPods clean-audio click toggle
./bin/cordkey --play right_option --hold-ms 300 --tap space # multi-action hold + short tap
